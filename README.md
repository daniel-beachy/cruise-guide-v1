# Koningsdam Voyage Guide

An offline phone guide to our Holland America Mexican Riviera cruise, Dec 26, 2026 – Jan 2, 2027.

**Open it:** https://daniel-beachy.github.io/cruise-guide-v1/ in Safari → Share → Add to Home Screen →
open it once. After that it works in airplane mode.

What's inside: an interactive route chart, day-by-day plan, night-sky planner, deck explorer, a
diesel-electric power lab, port pages with day "vibes", maps, history and facts, travel-advisory
background, a wildlife field guide with photos, trivia, card-game rules and a packing list.

Build: `pip install ephem pillow && python3 src/build.py` (see [CLAUDE.md](CLAUDE.md)).

Photos: Wikimedia Commons contributors (credited on each card). Coastlines: © OpenStreetMap
contributors (ODbL) and Natural Earth, via geo-maps. Fonts: Newsreader and Martian Mono (SIL OFL).
